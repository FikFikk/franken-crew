# FrankenCrew demo video (Remotion)

The Kiroween 2026 demo video, built in code with [Remotion](https://www.remotion.dev/) 4. The design, the
scene list, and the rules it follows are in [docs/REMOTION_VIDEO.md](../../docs/REMOTION_VIDEO.md); the
narration is in [docs/DEMO_VIDEO_SCRIPT.md](../../docs/DEMO_VIDEO_SCRIPT.md).

Everything on screen comes from the repository: the Graveyard footage and screenshot, `ui/data/replay.json`,
the spec, the steering files, the hook, `app.json`, and live output of the chaos suite, the property tests,
and `franken guard`. `npm run data` regenerates all of it.

## Commands

Node 20.19+, 22.13+, or 24+. `npm run data` also needs Go and git.

| Command | What it does |
|---|---|
| `npm install` | Install Remotion and the other dependencies |
| `npm run data` | Rebuild `src/data/` from the repo (runs the chaos suite, the property tests, and `franken guard`) |
| `npm run dev` | Open Remotion Studio to preview and scrub |
| `npm run stills` | Render two stills per scene to `out/stills/` (`-- --cues` adds one per cue, `-- 1200 2400` renders those frames) |
| `npm run captions` | Transcribe `public/vo/*.wav` with a local Whisper.cpp into `public/captions/*.json` |
| `npm run render` | Render `out/frankencrew-demo.mp4` (1080p, H.264, CRF 18) |
| `npm run preview` | Render a quick half-size `out/frankencrew-preview.mp4` |
| `npm run srt` | Write `out/frankencrew-demo.srt` for the YouTube upload |
| `npm run thumbnail` | Write `out/thumbnail.png` from the closing frame |
| `npm run lint` | ESLint and TypeScript |

## Workflow

1. `npm run data`, then `npm run dev` and watch the silent cut. Without a voiceover, every scene uses its
   budget length and the cue frames are estimated from the narration text.
2. Record the seven narration paragraphs as `public/vo/01-hook.wav` … `07-outro.wav` (one take per scene).
3. `npm run captions`. Fix misheard words in `public/captions/*.json` by hand and keep the times. Scene
   lengths now follow your voice, and every animation cue lands on its spoken word.
4. `npm run dev` again and scrub each scene. The render fails on purpose if the video is longer than 2:55.
5. `npm run render`, `npm run srt`, `npm run thumbnail`, then upload to YouTube as described in
   `docs/DEMO_VIDEO_SCRIPT.md`.

Optional real footage: put a phone recording of a FrankenCrew poll (numbers blurred) at
`public/footage/phone-poll.mp4` and a Kiro Crew dashboard recording at `public/footage/crew-dashboard.mp4`.
The video uses them automatically. Both paths are in `.gitignore` because they can show private data.

## Layout

```text
scripts/            collect-data, stills, make-captions, make-srt
src/script.ts       scenes, budgets, voiceover files, cue words
src/timeline.ts     scene lengths from the voiceover, cue frames from captions or the text
src/Root.tsx        composition and calculateMetadata (2:55 limit)
src/scenes/         S1Hook … S7Outro
src/components/     footage frame and time warp, step rail, stamps, phone, chart, terminal, captions
src/data/           generated by npm run data (committed)
public/             footage, images, voiceover, captions
```

This folder has its own `go.mod` so that `go vet ./...` at the repository root skips `node_modules`.
